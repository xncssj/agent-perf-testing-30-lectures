## 2. 非流式基准（50 样本）

| 指标 | Mean | P50 | P90 | P99 | Min | Max |
|---|---|---|---|---|---|---|
| E2E (ms) | 2266.2 | 2330.0 | 2552.8 | 2670.7 | 1587.4 | 2729.1 |
| TTFT (ms，合成) | 2876.4 | 2919.4 | 3175.3 | 3369.0 | 2121.6 | 3413.6 |

- 合格业务 50/50 = 100%；E2E P90 2552.8ms（约 2.55 秒），计时止点为引擎内部执行结束。
- 非流式接口的 TTFT/TPOT 为合成口径（决策耗时 + 配置 token 间隔），仅作对照，不是客户端实测值。

## 4. T00001 服务端事件时序

一笔工单（T00001）的服务端事件按相对请求开始的时刻排开：

| 时刻 | 事件 |
|---|---|
| 0.017ms | `thinking`（服务端发出处理提示） |
| 658ms | 决策 1（query_order）执行完成 |
| 1301ms | 决策 2（query_logistics）执行完成 |
| 2498ms | 首 `answer`（首个答复 Token） |

- 该记录包含 3 次规划调用（规划循环 3 次「决策→睡眠」串行，约 0.5—0.7s/次），首 Token 前必须等完整规划链结束。
