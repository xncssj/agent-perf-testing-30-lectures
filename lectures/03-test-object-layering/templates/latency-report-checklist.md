# 时延口径自查表

来源：课程第 03 讲思考题“口径自查表”，结合“三种时间不能直接做减法”及分层测试对象说明。对报告中每个时延数字逐项填写，不能仅凭字段名称猜测计时含义。

## 核心填写区

| 要填的项 | 本报告的答案 |
|---|---|
| 属于哪一层 | |
| 起止点在哪里 | |
| 统计单位是什么 | |
| 能支持什么范围的结论 | |

以上任一项不明确，先记“口径待补”，再确定补采哪层证据。

## 证据复核

| 核对项 | 本报告的答案与证据 |
|---|---|
| 业务、运行、请求／步骤／轨迹标识能否关联同次运行 | |
| 客户端或服务端采集，时钟基准及时间单位 | |
| 起点是否包含业务排队，终点是否包含流式收尾及必要验证 | |
| 单次耗时、累计时间、事件时刻或业务墙钟时间 | |
| 字符、词元、片段或网络事件的测量粒度 | |
| 批次、统计窗口、样本量、分位数算法 | |
| 成功、失败、超时、取消、缺失及不适用数量 | |
| 并行、重试、父子关系与等待证据是否齐全 | |
| 数据、配置与判据版本；当前结论和待补项 | |

## 实验示例及使用边界

| 实验读数 | 能说明什么 | 不能怎样使用 |
|---|---|---|
| 工单 T00001 的 658、1301 毫秒 | 相对请求开始的工具执行完成时刻 | 不是 2 次工具各自的耗时，不能相加作为累计执行时间 |
| 20 笔历史流式端到端第 90 百分位 4788.4 毫秒，约 4.79 秒 | 该客户端样本批次到输出收尾的时延分布 | 不是 T00001 的单笔总时长，不能与其 4 个事件时刻拼接比较 |
| 历史相邻字符事件间隔第 90 百分位 40.8 毫秒 | 模拟模型的字符输出节奏 | 不是词元平均耗时，也不代表真实模型词元生成速度 |

这些数值来自[案例 1 实验记录](../experiments/case-1-single-agent.md)，仅用于口径演示。模型与工具累计时间可能重叠，不能从整笔墙钟时间中直接相减反推排队；需补齐时间线及等待原因。记录结构见[时间口径记录](time-boundary-record.md)。
