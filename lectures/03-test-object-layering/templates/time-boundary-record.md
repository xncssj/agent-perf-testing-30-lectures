# 时间口径填写区

来源：课程第 03 讲“三种时间不能直接做减法”“业务起止点，要从用户目标反推”及“事件时间轴表”。本表记录同次运行的时间边界与关系，不用累计耗时反推缺少观测的排队时间。

## 口径定义

| 时间类型 | 定义 | 使用限制 |
|---|---|---|
| 业务墙钟时间 | 业务约定起点到交付或其他终态的真实经过时间 | 不等于所有组件耗时之和；业务排队不能漏计 |
| 模型调用累计时间 | 同次运行各模型调用持续时间之和 | 并行调用可能重叠，不与业务墙钟直接相减 |
| 工具执行累计时间 | 同次运行各工具操作持续时间之和 | 与模型、其他工具可能重叠；注明是否含网络和重试 |
| 事件时刻 | 相对同一计时基准记录的动作发生时点 | 时刻不是持续时间；不能累加事件时刻充当调用耗时 |

## 分段时间线填写区

| 事件／调用／步骤标识 | 父标识 | 类型与计时边界 | 开始时刻 | 结束时刻 | 持续时间及单位 | 并行或重叠段 | 等待原因 | 终态及证据位置 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

只有瞬时事件时填写其发生时刻，持续时间记“不适用”；缺开始或结束记录时写“待补”，不能用 0 代替。平台“模型用时”“工具用时”先确认是单次值还是累计值，再纳入记录。

## 历史实验示例

[事件时间轴表（工单 T00001）](../experiments/case-1-single-agent.md)记录 0.017、658、1301、2498 毫秒的服务端事件。658、1301 毫秒对应工具执行完成，不是规划决策耗时；该次运行发生 3 次规划调用，是决策驱动的实际循环，不是固定安排的 3 轮。

20 笔流式样本的 4.79 秒是另一组客户端第 90 百分位，不当作这笔工单墙钟时间。历史字符流与确定性词元边界批次分别记录，字符事件间隔不写成 TPOT。完整业务和局部基准应配对采集，结论只覆盖明确的边界与样本。
