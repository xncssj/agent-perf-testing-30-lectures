# Goodput 与成功业务成本台账

来源：课程第 01 讲“‘完成’还不够：结论要过质量、时延、安全三关，还要算成本这笔账”，并按第 04 讲成本算式表统一统计口径。以下是填写模板；算例明确标为示意。

## 填写前约定

| 字段 | 填写内容 |
|---|---|
| 批次、冻结业务运行清单、数据与判据版本 | |
| 业务目标、交付边界与各类终态 | |
| 质量、单笔时延、安全判据及证据位置 | |
| 成本预算、计价版本、币种与资源分摊规则 | |
| 首笔提交与最后约定终态时间戳 | |
| 报告版本、缺失证据、复核人／时间 | |

## 逐笔依据

| 业务标识 | 运行标识 | 提交／终态时间 | 终态与是否业务完成 | 质量状态 | 时延状态 | 安全状态 | 是否计入合格数 Q | 全部执行成本 | 证据位置 |
|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | |

判定分别使用“通过／失败／未验证”。同一运行的重试沿用运行标识，保留尝试和费用明细，但不重复增加运行总数或合格数；同一业务再次试验使用新的运行标识。

## 汇总台账

| 统计窗口及秒数 T | 原始运行总数 N | 业务完成数 B | 质量合格数 | 时延合格数 | 安全合格数 | 三项交集合格数 Q | 未验证数 | Goodput（业务/秒） | 总执行成本 C | 成功业务成本 | 成本验收结论 | 报告版本与证据 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---|---|---|
| | | | | | | | | | | | | |

质量、时延、安全各列用于排查；Q 必须从同批逐笔记录取 3 项全通过的交集，不能将这 3 列相加或将各自通过率直接相乘。业务目标达到才计入 B；成本独立判定，不改变 Q。第 01 讲完整结果合格率若包含成本，须另列其判据及分子。

| 指标／字段 | 算法或定义 | 边界处理 |
|---|---|---|
| N | 开测前冻结的运行总数 | 失败、超时、取消、未验证均保留，不删除慢业务 |
| T | 首笔提交至全部运行达到约定终态，单位秒 | 包含业务排队、执行、重试；必须大于 0，未全部收尾前只报暂定统计 |
| 原始业务吞吐 | N ÷ T | 不等同于稳态容量 |
| 业务完成率 | B ÷ N | N 为 0 时不适用 |
| Goodput | Q ÷ T | 未验证不计入 Q；Q 为 0 时为 0 |
| 总执行成本 C | 同批全部运行消耗 | 含失败、超时、重试及未达标运行，按统一币种和分摊规则汇总 |
| 成功业务成本 | C ÷ Q | Q 为 0 时写“无合格业务”，单位成本记“不可计算”，仍报告总成本 |

证据不足与已证明失败分开记录，二者均不计入 Q。事后评测回填可更新 B、Q 和派生值，但保留原清单和报告版本。

## 计算示例
