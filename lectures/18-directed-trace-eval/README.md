## 使用方式与证据状态

1. 正常、慢、失败三类样本必须同批运行、同业务类型，并逐笔对齐 Task ID／Run ID／Trace ID。
2. 单样本不下结论；先做同族对照，再看差异落在哪一段。
3. span 分解是量级证据，完整时间恒等式仍以逐笔判定与 S3 为准。
4. 工具执行时延、资源占用与业务结果要分开核对，不能用一个指标替代另一个。
5. 观测缺口如实登记；没有直接证据的段落不写成已确认。
