**结论（三方互证）**：

2. **decision 为已测成分的主体（2026-10-19 补界：逐笔等式未闭合）**：按工具数分层（0/1/2/3+）的 decision 合计 P50 = 1,111 / 2,496 / 3,356 / 4,642 ms——与 S3 瀑布（1.1 / 5.4 / 8.0 / 9.9s）同向增长；单次 decision P99 3,901ms 即推理型长尾的直接观测；7,147 笔逐笔复算「首字−decision−tool」剩余段中位约 3.0s（见 §二 复核），「主体」表述以已测成分为限。
