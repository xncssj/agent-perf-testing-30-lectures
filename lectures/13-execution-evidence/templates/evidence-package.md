# 证据包与数据质量说明

参考课程第 13 讲“数据质量说明与最小包裹”中的“报告段落表”与“证据包清单表”。使用说明见[本讲说明](../README.md#使用方式与证据状态)。

## 数据质量说明五段

| 段落 | 写什么 | 示例落点 |
|---|---|---|
| 有效运行集合 | 哪些轮核验合格、证据包齐 | 真实模型轮七轮 7/7 PASS、`error_rate` 全程 0 |
| 无效与 NOT_VERIFIED | 中止、被污染、缺样本的轮次与原因 | 工程冒烟轮留档不入读数；被掐停、被打断的轮次同理 |
| 缩短版与未测项 | 长稳实际时长、无网关直连对照、真实模型 | 30 分钟折中口径如实标注；全时长回填仍登记 |
| 口径与版本 | 模型口径、网关、观测上报分开记；数据版本以勘误为准 | 真实轮 v1.1、`deepseek-flash`、SLO 20000ms；Mock 轮 SLO 10000ms、2 元/千 Token 演示价分列 |
| 失败与 FAIL | 失败笔数、归因、是否保留 | 真实轮 8917 笔中 47 笔不合格：未完成 40、时延超标 8、重叠 1 |

## 最小证据包清单

| 分类 | 内容 | 谁消费 |
|---|---|---|
| 运行集合 | 有效运行清单、NOT_VERIFIED 列表与原因 | 压力数据分析（第一步） |
| 压力主读数 | 逐阶梯、逐场景的吞吐、时延、合格率、成本，带口径 | 压力曲线与端到端拆分 |
| 环境与事件 | 双路监控事件流、部署与人工介入事件 | 全局观测对照 |
| 失败与轨迹索引 | 失败业务标识、可回读路径、链路追踪标识 | 定向 Trace 与逐笔评测 |
| 质量说明 | 上面五段 | 全程 |

## 归档核对

| 核对项 | 证明什么 | 不能证明什么 |
|---|---|---|
| 哈希清单 | 文件没改过 | 结论是对的 |
| 归档回执 | 上传后回读一致 | 内容正确 |
| 逐笔样本前 200 行脱敏副本 | 可抽查、可回读 | 全量样本完整 |
| 聚合判定文件 | 当轮三态结论 | 人工复核已完成 |

## 判定边界

- 只有摘要、没有回读路径的“结果”，到定向 Trace 一步就会扑空。
- 逐笔原始产出可以不入库，但必须留索引；证据包缺一项，不宣布可以开始分析。
- 前提（如首字节门槛优化与配对复测）不能因为一个绿勾被抹掉；绿勾可以少，前提不能少。
- 失败业务逐条保留可回溯；未执行场景写清原因与恢复条件，不许隐去。
