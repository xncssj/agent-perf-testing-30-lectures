# 第 13 讲配套资料

本讲主题：测试执行过程中记录什么，才能让结果经得住质疑？

本目录提供 3 份模板，对应正文中的轮次清单表、质疑应答表、对比读数表、异常归属表、报告段落表与证据包清单表。本目录不包含正文图片、项目源码或逐笔原始数据。

## 模板

| 模板 | 用途 |
|---|---|
| [轮次清单与七项运行记录](templates/run-record.md) | 两道开跑检查加五个正式场景的顺序、样本量、七项质疑应答与单轮节拍 |
| [证据包与数据质量说明](templates/evidence-package.md) | 数据质量说明五段、最小证据包五类、归档核对能证明与不能证明什么 |
| [对比读数与异常归属](templates/anomaly-attribution.md) | 三轮读数分列口径、三类异常归属、面板与实测的四条规矩 |

## 使用方式与证据状态

1. 跑完不算数，核验过才算数；三态结论、退出码、中止记录与样本完整性一起复核。
2. 引用读数带齐四个口径标签：压测环境、模型口径、网关链路、观测上报状态。
3. 异常先排除污染、干净后重跑复现，再归因；不许先入为主。
4. 失败、异常值、观察项一个不删；零样本阶梯、缩短版、未测项写进质量说明。
5. 哈希只证明文件没改过，回执只证明上传后回读一致，都不证明结论正确。
