# 第 11 讲配套资料

本讲主题：基准、容量和稳定性场景怎样组合，才能覆盖项目风险？

本目录提供 3 份模板，对应正文中的场景动机表、场景总表、基准／容量／稳定性／异常／多轮设计表、指标目标表与暂停线表。本目录不包含正文图片、项目源码或逐笔原始数据。

## 模板

| 模板 | 用途 |
|---|---|
| [场景矩阵](templates/scenario-matrix.md) | 每类场景对到一个业务风险，并用一张总表收口输入、压力、观测、停止条件与验收阈值 |
| [场景设计表](templates/scenario-design.md) | 基准、容量、稳定性、异常、多轮的逐项设计理由与边界 |
| [阈值与停止条件](templates/thresholds-and-stop-lines.md) | 从业务承诺、基线实测、成本上限三处倒推阈值，并固定五条暂停线 |

## 使用方式与证据状态

1. 先写业务风险，再填压力参数；组合顺序固定为基准 → 容量 → 稳定 → 异常／恢复。
2. 每张场景表写全输入、压力、观测、停止条件、验收阈值五要素。
3. 容量阶梯同池同哈希，逐级引用本级摘要；稳定性缩短版只观测，不据此下全时长结论。
4. 异常与多轮按段／按轮判定，不能拿最好的一段代表整场。
5. 状态列如实写“缩短版”“旧链路”“未测”“待校准”，不把组合完整当成已验收。

## 参考章节与使用说明

- 参考课程第 11 讲“先把每一类场景对到一个业务风险上”“基准：先把基线跑明白”“容量：看它在哪一级开始衰减”“稳定性：两分钟跑不出一个夜晚”“异常：主动抖一下，看它怎么收场”“多轮会话：用户会追问，上下文会膨胀”“阈值不能拍脑袋：从业务倒推，用基线校准”“停止条件：先想清楚什么情况下必须停”“汇总表：本讲交付物落在一张纸上”。各模板均在文件开头标注对应表名。
- 模板中的示例阈值取自客服工单案例，只用于说明写法；换成自己的项目时从业务承诺、基线实测与成本上限重新倒推。
