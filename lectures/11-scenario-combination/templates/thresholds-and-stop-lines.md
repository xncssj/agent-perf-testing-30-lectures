# 阈值与停止条件

参考课程第 11 讲“阈值不能拍脑袋：从业务倒推，用基线校准”“停止条件：先想清楚什么情况下必须停”中的“指标目标表”与“暂停线表”。使用说明见[本讲说明](../README.md#使用方式与证据状态)。

## 指标目标表

| 指标 | 压测环境目标 | 为什么是这个数 | 本项目填写 |
|---|---|---|---|
| Goodput | 每个台阶或整轮单独记录（合格业务／秒）；业务所需 ×2 满足才升 VU | 两套目标必须留余量 |  |
| E2E P90 | ≤ 10s（压测环境候选） | 生产 ≤ 15s 扣掉环境差异 |  |
| 合格率 | ≥ 98%（压测环境） | 生产 ≥ 95% 的收紧版 |  |
| 错误率 | ≤ 0.5%（压测环境） | 生产 ≤ 1% 的收紧版 |  |
| TTFT | 流式专项单独采集 | 正式执行时段走非流式，采不到 |  |
| TPOT | 流式专项单独采集 | 依赖 Token 边界证据 |  |
| 成本／Token | 分窗口单独记录；上限由业务成本目标反推 | 未回填前不当验收项 |  |

阈值从三处倒推：业务承诺（生产目标）、基线实测（系统能力）、成本上限（单元经济）。三者缺一，目标值只能标“候选”。

## 暂停线表

| # | 触发条件 | 动作 |
|---|---|---|
| 1 | 错误率连续 2 分钟超过 5% | 暂停场景，保留现场 |
| 2 | 合格率较同台阶基线掉超过 5 个百分点 | 暂停，先查口径再决定是否续跑 |
| 3 | 服务端非正常终态计数持续上涨 | 暂停，查运行循环与依赖 |
| 4 | 单位时间 Token 消耗超过同台阶基线 2 倍 | 暂停，查循环轮次与重试 |
| 5 | 环境被变更（依赖升级、数据集重生成、他人同机作业） | 暂停，该轮记 NOT_VERIFIED |

真打起来人是慌的：数字一难看，第一反应是“再跑一会儿看看”。先把停止条件写进方案，触发就停，停完看证据再决定，不靠现场手感。

## 校准规则

- 隔离环境先跑一轮真实模型校准窗，重新定达标阈值，再开 Mock 正式容量。
- 业务链路或数据集版本一变，基线重跑，旧阈值作废。
- 容量逐级判定；稳定性看末段；异常分段核对；多轮分轮核对。

## 判定边界

- 压线算达标，未验证不算达标。
- 阈值不是越严越好；过严会逼着执行环节改样本，过松会放过真实退化。
- 暂停线触发不等于失败结论；它只说明这轮不再具备下结论的资格。
