# 性能指标字典

先确定业务问题，再选择能回答该问题的指标。请求、步骤、轨迹和业务分别定义测量边界；业务验收以整笔业务为准，组件读数用于解释原因。

## 定义参考表

| 指标 | 层级与单位 | 计算或记录方式 | 证据与用途 |
|---|---|---|---|
| 首词元时延（TTFT） | 请求级，毫秒 | 模型请求发出至收到首个输出词元；含网络、推理服务排队与输入处理，不含发请求前的业务排队 | 客户端流式时间戳，解释首输出等待；用户可见首段反馈另立边界 |
| 输出词元平均耗时（TPOT） | 请求级，毫秒/词元 | 首个到最后 1 个输出词元的时长 ÷（输出词元数−1）；输出不足 2 个词元时不适用，协议结束信号另记 | 真实词元计数与时间戳，解释平均生成速度；不代表每个相邻间隔 |
| 相邻输出间隔（ITL） | 请求内，毫秒 | 记录相邻输出词元的间隔及其分布；部分工具把其均值定义为 TPOT | 注明工具定义，避免同一聚合指标重复上报；字符／事件间隔须另名 |
| 请求时延 | 请求级，毫秒 | 请求发出至响应结束、失败或超时 | 请求标识、响应与终态，检查模型或工具调用 |
| 输入与输出词元用量 | 请求级，词元 | 逐调用分别记录，再按运行汇总 | 用量记录，核对上下文增长与模型费用 |
| 上下文窗口占用率与构成 | 请求级或会话级，比例 | 当前上下文词元数 ÷ 模型窗口上限；按系统提示、工具参数结构、用户消息、注入上下文、助手回复、工具结果 6 类分列 | 上下文记录，定位容量被谁占用 |
| 提示词缓存命中率 | 请求级或会话级，比例 | 缓存读取词元数 ÷ 总提示词词元数，未命中与缓存写入分列 | 用量及实际账单，核对缓存收益 |
| 输入与输出词元吞吐 | 请求集合，词元/秒 | 同窗口对应词元总数 ÷ 窗口秒数，输入与输出分别记录 | 推理记录，观察服务吞吐，不等同业务交付 |
| 单步耗时 | 步骤级，毫秒或秒 | 步骤开始至步骤终态，保留内部请求与等待区间 | 步骤时间线，定位慢步骤及其子请求 |
| 工具调用耗时 | 请求级或步骤级，毫秒或秒 | 分别按工具接口请求、完整工具操作边界记录 | 工具记录，注明是否包含网络、等待与重试 |
| 工具参数正确率 | 步骤级，比例 | 工具选择与参数均符合判据的调用数 ÷ 同批调用总数 | 输入、参数及断言，未知记录保留并单列 |
| 迭代轮次与终止原因 | 轨迹级，次与分类 | 逐运行记录轮次和终态，按业务类型看分布 | 执行轨迹，检查调用放大、预算耗尽与停止行为 |
| 轨迹效率 | 轨迹级，比例 | 经复核的有效步骤数 ÷ 总步骤数 | 步骤标注，解释路径是否绕行；记录标注覆盖率 |
| 冗余词元占比与成本浪费率 | 轨迹级，比例 | 可避免词元数 ÷ 总词元数；可避免成本 ÷ 总成本 | 标注及用量明细，注明覆盖率，不把未标注部分默认为有效或零浪费 |
| 端到端业务时延 | 业务级，秒 | 业务提交至交付或其他约定终态 | 业务时间戳，成功、失败、超时与取消分别报告数量和分布 |
| 业务排队时延 | 业务级，毫秒或秒 | 进入业务队列至首次开始执行，后续排队另记 | 队列事件，不重复累加模型侧排队 |
| 业务完成率与结果合格率 | 业务级，比例 | 业务完成率为 B ÷ N；结果合格率按预先声明的全部验收约束统计合格数 ÷ N | 结果复核与各项验收状态；若结果合格率判据含成本，须与 Q 的三项交集明确区分 |
| 原始业务吞吐与有效吞吐 | 业务级，业务/秒 | 固定批次分别为 N ÷ T、Q ÷ T；Q 为质量、时延、安全交集，T 大于 0 | 同批清单、终态与判据，区分结束速率与有效交付 |
| 成功业务成本 | 业务级，货币/业务 | 全批执行成本 C ÷ Q；Q 为 0 时不可计算 | 全批成本及判定明细；成本独立验收，不改变 Q |

N、T、B、Q、C 的完整定义、逐笔填写区及边界处理见[有效吞吐口径表](goodput-ledger.md)。

## 报告填写区

| 指标 | 分子／分母或样本量 | 观察值与单位 | 判据及版本 | 未验证／缺失／不适用 | 覆盖范围与证据 | 结论状态 |
|---|---|---|---|---|---|---|
| | | | | | | |

分位数同时报告样本量与算法，可按第 50、90、99 百分位及最大值查看分布。比例汇总优先累加分子、分母，不能直接平均长短不同轨迹或样本量不同批次的比例；分母为 0 时记不适用。

大量快速失败可能拉低平均时延，只看成功记录又会漏掉失败规模。运行状态、数据缺失与抽样覆盖范围应和指标一起报告。

## 选用示例：按业务问题选指标

| 问题 | 先选指标 | 同次运行的诊断证据 | 示例状态 |
|---|---|---|---|
| 用户迟迟拿不到配送答复 | 端到端业务时延、业务完成率 | 排队、轨迹、步骤与请求时间线；首屏无反馈时加用户可见首段时间 | 选择方法，非实测结论 |
| 成功交付的成本上升 | 成功业务成本与独立预算结论 | 模型用量、工具次数、经复核的浪费项与账单 | 选择方法，非实测结论 |
| 需要确定容量 | 同业务组合逐档记录有效吞吐、时延、完成率与成本 | 到达率、实际业务并发、队列与下游调用；不能用模型并发代替业务并发 | 需实际负载与完整证据，不由固定批次直接宣称稳态容量 |
