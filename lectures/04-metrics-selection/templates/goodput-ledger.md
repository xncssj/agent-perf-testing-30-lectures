# Goodput 口径表

## 批次锁定

固定批次口径：开测前冻结业务运行清单，运行内部的重试保留原运行标识，每次运行在 Goodput 分子里至多出现一次。

| 字段 | 定义与单位 | 本批填写 | 复核要求 |
|---|---|---|---|
| N | 冻结清单中的业务运行总数，次 | | 失败、超时、取消、未验证记录全部保留 |
| T | 首次提交至全批约定终态的窗口时长，秒 | | 大于零，保留起止时间戳 |
| B | 达到业务目标的运行数，次 | | 对照工单判据与结果证据 |
| Q | 同批满足质量、时延、安全三项要求的运行数，次 | | 每次运行去重计数，保留判据版本与证据位置 |
| C | 同批全部运行的总执行成本，统一币种 | | 包含失败、重试及不达标运行 |
| 业务级 Goodput | Q ÷ T，业务/秒 | | 未验证记录不计入 Q |
| 成功业务成本 | C ÷ Q，货币/业务 | | Q 为零时报告“无合格业务”和总成本 |

## 换算核对

```text
原始业务吞吐 = N ÷ T
业务完成率 = B ÷ N
完成业务中的其余约束达标率 = Q ÷ B
业务级 Goodput = (N ÷ T) × (B ÷ N) × (Q ÷ B) = Q ÷ T
成功业务成本 = C ÷ Q
```

B 为零时直接报告 Q = 0、Goodput 为零，不计算 Q ÷ B。全部指标必须来自同一批记录。
