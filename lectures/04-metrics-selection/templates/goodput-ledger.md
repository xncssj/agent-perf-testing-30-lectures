# 有效吞吐口径表

业务级有效吞吐（Goodput）按同批、同时满足质量、时延和安全要求的完整业务运行统计。成本单独给出验收结论，不进入合格业务数 Q 的判定。

## 批次填写区

| 字段 | 填写内容 |
|---|---|
| 批次、报告版本及复核人 | |
| 业务类型、业务集与冻结清单位置 | |
| 数据、配置与判据版本 | |
| 质量、单笔时延与安全判据及证据要求 | |
| 批次服务级别目标与达标比例要求 | |
| 成本预算、币种、计价版本与资源分摊规则 | |
| 首笔提交时间、最后约定终态时间 | |
| 约定终态与交付边界 | |
| 未验证记录、成本缺口及当前发布状态 | |

窗口从首笔业务提交到冻结清单中全部运行到达约定终态，包含业务排队、执行和重试。成功、失败、超时、取消分别记录终点；交付前必需的验证计入等待，事后离线评测只回填判定，其耗时单列。

## 逐笔运行填写区

同一业务可重复试验，每次使用独立运行标识；运行内部的重试保留原运行标识，重试尝试明细关联该运行，不重复增加 N 或 Q。

| 业务标识 | 运行标识 | 提交／终态时间与终态 | 达到业务目标 | 质量判定 | 时延判定 | 安全判定 | 是否计入 Q | 全部执行成本与币种 | 答复、轨迹、用量及判定证据 |
|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | |

各项判定使用“通过／未通过／未验证”；缺证据不等于已证明失败，但不计入 Q。安全证据须包含是否拦截、拦截内容与最终交付；按契约正确拒绝越权查询可以合格，正常业务被拦且未交付通常不算完成。

## 计数与计算定义

| 字段／指标 | 定义与算法 | 复核要求 |
|---|---|---|
| N | 冻结清单中的运行总数，次 | 失败、超时、取消和未验证记录全部保留，不删除慢业务 |
| T | 首次提交至全批约定终态的窗口时长，秒 | 必须大于 0；保留起止时间戳，全部运行到终态后才发布最终值 |
| B | 达到业务目标的运行数，次 | 对照业务判据和最终结果，不以流程结束代替业务完成 |
| Q | 同批质量、时延、安全 3 项全通过的运行数，次 | 按运行求交集并去重；不能将 3 项边际通过率直接相乘；通常有 0 ≤ Q ≤ B ≤ N |
| C | 同批全部运行的总执行成本，统一币种 | 包含失败、重试和不达标运行，逐调用登记输入／输出及其他计费用量，再加工具费用与约定资源分摊 |
| 原始业务吞吐 | N ÷ T，业务/秒 | N 中全部运行达到终态后计算，不等同稳态容量 |
| 业务完成率 | B ÷ N | N 为 0 时不适用，不能报 100% |
| 业务级有效吞吐 | Q ÷ T，业务/秒 | Q 为 0 时有效吞吐为 0；不得用缺少安全核验的脚本合格数冒充 Q |
| 成功业务成本 | C ÷ Q，货币/业务 | Q 为 0 时写“无合格业务”，保留 C，单位成本记“不可计算” |

业务判定证据未齐时，Q 及其派生指标只报暂定统计，注明覆盖范围与缺口；未验证记录不计入 Q。评测回填可更新 B、Q 和派生指标，但保留报告版本与变更记录，不修改冻结清单以隐藏未达标记录。费用无法归集时标“待补”，成本结论标“暂定”。

N、B、T 均为正且来自同批记录时，有效吞吐可分解为：`(N ÷ T) × (B ÷ N) × (Q ÷ B) = Q ÷ T`。B 为 0 时直接报告 Q=0，不计算 Q ÷ B；N 为 0 时相关比例不适用。

## 四项约束核对

| 约束 | 检查内容 | 证据与计数方式 |
|---|---|---|
| 质量 | 业务目标、事实准确性与完整性 | 对照指定订单物流快照、最终答复及评测记录，缺证据记未验证 |
| 时延 | 单笔是否满足门槛，全批是否满足服务级别目标 | 保留业务时间戳，分终态报告数量与时延分布 |
| 安全 | 权限与信息披露等契约 | 保存护栏结果与实际交付内容，按业务类型区分正常交付和预期拒绝 |
| 成本 | 单笔上限、批次预算或单位成功业务成本 | 按事前选定口径独立验收，不改变 Q |

## 算法示例（非实测）

| N | T（秒） | B | Q | C | 原始业务吞吐 | 业务完成率 | 有效吞吐 | 成功业务成本 | 状态 |
|---|---|---|---|---|---|---|---|---|---|
| 100 | 10 | 80 | 60 | 12 元 | 10 业务/秒 | 80% | 6 业务/秒 | 0.20 元/业务 | 示意，非实测 |

12 元包含整批失败与重试消耗。完成业务中的其余约束达标率是 Q ÷ B，即 75%；B 为 0 时直接记 Q=0，不计算 Q ÷ B。
