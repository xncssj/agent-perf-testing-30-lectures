# 监控面板核对清单

工具或平台自带的统计页面，读数抄进报告前先核口径。

| 面板读数 | 本课认可的口径 | 抄进报告前要做什么 | 本报告核对结果 |
|---|---|---|---|
| TPS | 本课 TPS 指事务吞吐；面板 TPS 常指每秒输出 Token 数 | 先核对单位与分母，Token 速度统一写 Tokens/s | |
| 首 Token 平均 | 算术平均，分母只含记录了首 Token 的步骤 | 按分位数重算，写清样本量与缺失部分 | |
| 输出速度 | 总输出 Token 数 ÷ 首 Token 之后的解码时长合计 | 只当解码期平均速度，不当服务吞吐，也不反推 TPOT 分布 | |
| 模型用时、工具调用用时 | 累计时间，不是墙钟时间 | 不与端到端业务时延相减 | |
| 缺失与不适用记录 | 失败请求的 TTFT 记不适用，样本缺失不填零 | 缺失部分单列，不从分母里悄悄消失 | |
