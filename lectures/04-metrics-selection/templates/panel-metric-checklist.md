# 面板口径核对清单

将面板读数写入报告前填写。记录缺失、算法不明或证据未齐时，状态写“待补”或“未验证”，不能填零或默认通过。

## 填写区

| 字段 | 填写内容 |
|---|---|
| 业务问题与报告版本 | |
| 运行批次、业务集及数据版本 | |
| 面板名称、工具版本与采集位置 | |
| 统计窗口及起止时间 | |
| 判据、服务级别目标及其版本 | |
| 当前状态、缺口与复核人 | |

每个准备采用的读数填写 1 行；比例保留分子、分母，时延分位数同时保留样本量和算法。

| 面板原名与读数 | 统计对象与层级 | 测量起点／终点 | 单位、算法及分子／分母 | 统计窗口 | 样本数、缺失数与不适用数 | 工具／判据版本 | 证据位置 | 核对结论与动作 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

## 工具读数对照

| 常见读数 | 核对口径 | 写入报告前的动作 |
|---|---|---|
| 每秒输出词元数，被面板简写为 TPS | 生成速度，与本课按事务计数的 TPS 不同 | 核对单位与分母，输出速度统一标明“词元/秒” |
| 首词元平均时延 | 只含记录到首词元的请求或步骤的算术平均 | 核对对象，补充分位数、样本量和缺失记录；不能代表全部业务等待 |
| 输出速度 | 总输出词元数 ÷ 首词元之后的解码时长合计 | 只作解码期平均速度，不当成服务吞吐，也不反推逐请求 TPOT 分布 |
| 模型用时、工具调用用时 | 调用累计时间，可能有并行重叠 | 与墙钟时间分开，不能直接与端到端业务时延相减 |
| 相邻输出间隔 | 先辨别词元、字符、片段或网络事件 | 字符事件间隔不能标成词元平均耗时；注明工具对 ITL 与 TPOT 的定义 |
| 失败请求与缺失样本 | 失败且无首词元时，该请求的首词元时延不适用；未采到数据另记缺失 | 两者分别计数，不能填零，也不能从总分母中悄悄删除 |

## 填写示例：字符间隔误作词元指标

| 项目 | 记录与处理 |
|---|---|
| 批次 | 历史流式 20 笔，字符粒度口径 |
| 原始读数 | 相邻字符事件间隔的第 90 百分位为 40.8 毫秒 |
| 核对结论 | 只能说明该批次的字符输出节奏，不能标成词元平均耗时（TPOT） |
| 首词元时延 | 同批第 90 百分位为 2472.6 毫秒；不能据此推导整笔业务时延 |
| 证据状态 | 历史批次记录；自己的报告仍须填写实际工具、时间戳与证据位置 |

该示例用于核对名称与测量粒度，不构成新旧版本的性能对照。
