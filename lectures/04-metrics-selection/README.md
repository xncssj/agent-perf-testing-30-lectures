# 第 04 讲配套资料

本讲主题：TTFT、TPOT、Goodput、质量和成本指标应该怎么选。

## 模板

| 可复用资产 | 用途 |
|---|---|
| [工具读数对照表](templates/panel-metric-checklist.md) | 将面板读数写入报告前，核对统计对象、边界、算法、窗口与版本 |
| [成本算式表](templates/goodput-ledger.md) | 冻结同批运行，逐笔核验质量、时延和安全，分别计算有效吞吐与成功业务成本 |
| [指标字典表](templates/metric-dictionary.md) | 按请求、步骤、轨迹和业务层级选择指标，登记单位、分母与证据 |

建议先核对面板读数，再按指标字典表确认采集字段，最后按成本算式表填写同批业务。成本算式表、四约束检查表和工具读数对照表已归入这 3 份模板。

模板对应课程第 04 讲“本讲交付”中的成本算式表、四约束检查表、指标字典表和工具读数对照表。表格的空白区用于填写自己的测试，注明“示意”的内容不代表实测结果。
