# SLO 指标落点表

参考课程第 09 讲“SLO 行怎么落到范围上”中的“指标落点表”。使用说明见[本讲说明](../README.md#使用方式与证据状态)。

## 指标落点表

| SLO 行 | 采集落在哪 | 范围策略提醒 | 本项目填写 |
|---|---|---|---|
| E2E P90（云端压测环境） | k6 客户端墙钟 | 必须真实压测被测 API；服务端耗时只作诊断 |  |
| 结果合格率 | 判定器 + 工单期望字段 | 数据快照进范围；生产库不进 |  |
| TTFT／TPOT | 流式专项脚本 | 非流式正式压测时段采不到 |  |
| Goodput | 合格业务数／墙钟时长 | 分子只数合格业务，分母是墙钟时长；Mock 窗标口径 |  |
| 可用性／恢复 | 稳定性与恢复窗 | 没跑长稳就登记待补，不拿缩短版充数 |  |

## 映射检查

- 每一行 SLO 是否都能在范围表找到采集落点。
- 找不到落点的行，是否进入风险清单并写明缺口与补证去向。
- 采集点是否标明“客户端”还是“服务端”，两个口径是否分列。
- 分子分母是否同源，是否写明统计窗口与环境。
- TTFT／TPOT 是否只在真实流式窗口采集，没有拿非流式估算。

## 判定边界

- 没有采集数据，目标就不能验收；空行不是“以后再说”，是本讲风险清单必须出现的缺口。
- 空行带进场景表，场景会假装自己已经覆盖。
- 落点上写“待补”的，不能在同一张报告里当成已通过。
