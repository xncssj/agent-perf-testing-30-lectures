## 使用方式与证据状态

1. 先验明正身再谈曲线；不算数的轮次留档但不进分析。
2. 四曲线同一组并发级别对齐；记“首个不达标阶梯”和“开始衰减阶梯”两个值。
3. 门禁全过不等于每笔完成；观察项先登记，未立窗前不写成异常窗。
4. 瓶颈可疑点只提候选：现象对得上文件、机制可证伪、缺口有主人、验证去向明确。
5. 小样本分位只作形态；不同模型口径不并排比数值。
