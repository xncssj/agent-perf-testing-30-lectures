## 使用方式与证据状态

1. 优化方案必须对准已证实或强候选的瓶颈成因，不对准就不动手。
2. 配对复测同场景、同数据、同环境、同口径，只改一处，并使用新的运行标识。
3. 有效吞吐、时延、质量、成本四项一起看，任一项回退就不能宣称有效。
4. 没执行完的方案写成申请单，基线不因一次参数对照而更换。
5. 新基线建立、报告发布与复测发起都属人工拍板点，不在分析步骤内自动完成。
