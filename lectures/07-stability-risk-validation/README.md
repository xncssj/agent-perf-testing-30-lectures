# 第 07 讲配套资料

本讲主题：服务没有报错，如何发现 Agent 稳定性出了问题。

本目录提供 4 份核心模板。风险地图附四状态与六机制验证表，五现象检测口径卡包含触发动作及筛查规则。课程正文请在专栏阅读，本目录不包含逐笔原始数据或可执行故障注入脚本。

## 模板

| 模板 | 用途 |
|---|---|
| [稳定性风险与验证目标地图](templates/stability-risk-validation-map.md) | 按风险、观测、验证相位和证据状态排期，附四状态与六机制 |
| [五现象检测口径卡](templates/five-symptom-detection-card.md) | 明确观测位置、阈值、触发动作及失稳筛查边界 |
| [四层注入矩阵](templates/fault-injection-matrix.md) | 区分模型、工具、编排与基础设施层的注入目标和证据 |
| [失效模式表](templates/failure-mode-analysis.md) | 按严重度、频度、探测困难度登记风险优先数及评分依据 |

## 使用方式与证据状态

1. 先填写业务、版本、统计对象、窗口与判据，把示意、实测和待测分开。
2. 稳定性验证依次记录稳态、扰动、恢复、复稳；错误、退化、扩散、恢复不完整是问题分类，不是这 4 个验证状态。
3. 约 20%、30%、2% 为课程示意阈值。质量退化、行为异常、模型路径异常这 3 个筛查方向中任意 2 类同时出现时触发排查，不是从 5 种现象中任取 2 种；该规则未经案例校准，不作容量硬门禁，停止加压与容量结论仍按第 06 讲判据。
4. 跨实例续跑 7/7 不等于真实进程或容器重启验证；12/12 降级不虚构事实不等于业务合格，也不等于 6 个机制全部验证完成。队列与压缩事件未采，高负载重试、服务侧限流、流式分档超时及副作用幂等仍有待测项。

## 证据图：真实模型长稳轮次的逐段漂移

![真实模型长稳轮次的分段读数、业务构成与样本边界](images/image%202.png)

图中记录 2026-10-14 的独立真实模型轮次：约 30.2 分钟、5526 笔，合格 5504 笔（99.60%），不合格 22 笔。分段分位数使用图中脚本的下中位数和最近秩第 90 百分位口径，只用于该轮段间比较；不能与整轮门禁的端到端第 90 百分位时延或模拟模型轮次直接混比。

**末窗不是完整的 5 分钟。** 图中前 6 段各 5 分钟，末段只覆盖 0.2 分钟、20 笔，不能代表稳态。判断漂移还要看业务构成及同族对照，不能只看聚合中位数上升 17.5%：图中列出 8 个业务族，其中异常业务族的首段中位数异常偏低、首末段变化约 226%，需单独核对；其余业务族的变化方向不一致。该轮拆分观察不能外推为所有场景均稳定，也不能仅凭聚合读数变慢宣布系统性失稳。图中的接口错误率为 0 仍不能替代业务合格判定。

## 参考章节与使用说明

- 参考课程第 07 讲“轨迹里的重试、轮次和队列，谁在悄悄涨”“四状态：稳态、扰动、恢复、复稳”“六个机制，只配不测不算数”“一张地图，管住排期和汇报”。各模板列出对应章节与表名。
- 风险地图用于排期与证据跟踪；检测口径卡用于记录观测与触发动作；注入矩阵用于分层设计实验；失效模式表用于登记评分及依据。
- 长稳图适用于该真实模型实验轮次，应结合业务构成、窗口长度和样本量解释分段读数。
- 失效模式评分为经验初估示例，不能当作已校准的项目评分；模拟批次不能用于回填发生频度。
- 填写区用于登记本项目观测、证据、去重口径与校准状态。队列没有评分，不参与本轮风险优先数排序。
