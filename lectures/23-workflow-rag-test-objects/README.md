## 使用方式与证据状态

1. 契约占比是覆盖率的分母，用例池占比是这一轮加压的流量构成，两组不能互替。
2. 覆盖率的分母是数据契约；契约里没有的分支，覆盖率再高也测不到。
3. 静态预检通过不等于数据装载生效，切档后仍要核对版本指纹与清单。
4. 路径与分支是严格判定项，意图与工具摘出来单独观测，判定口径以正文为准。
