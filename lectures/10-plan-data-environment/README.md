# 第 10 讲配套资料

本讲主题：需求和架构已经明确，测试方案、数据和环境应该怎样准备？

本目录提供 4 份模板，对应正文中的六件套清单表、方案要点表、工单分层表、环境口径表、版本指纹表、执行顺序表与缺口登记表。本目录不包含正文图片、项目源码或逐笔原始数据。

## 模板

| 模板 | 用途 |
|---|---|
| [测试方案六件套与要点页](templates/test-plan-six-parts.md) | 目标、指标、场景、数据、环境、验收六项落表，并拆开四个压力指标的单位 |
| [数据分层与准备检查](templates/data-stratification.md) | 六类工单分层、两条切分维度、生成式数据规矩与装载／质量核对 |
| [环境清单、版本指纹与执行顺序](templates/environment-checklist.md) | 双口径环境、四机角色、隔离红线、暂停线、六组指纹与七步执行顺序 |
| [方案缺口登记表](templates/gap-register.md) | 逐项登记未回填、未校准、待补的缺口，写清影响与责任人 |

## 使用方式与证据状态

1. 方案、数据、环境三样没落定之前，不执行压测。
2. 六件套逐项填写；每个窗口记录实际类型／难度／依赖返回构成。
3. 版本指纹六组关联到同一轮记录；界面选用不能替代实际运行指纹。
4. 缺口如实登记；登记缺口不等于完成验证，未测不得推断。
5. 本机冒烟结果不能当验收容量；正式结论只出自云端隔离压测窗口。
