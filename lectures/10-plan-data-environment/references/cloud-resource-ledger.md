# 压测实验室云资源清单（公开脱敏版）

> 对应第 10 讲正文引用的案例云资源台账。公开版只保留四机角色、网络分区、访问控制与生命周期口径；实例 ID、公网／私网 IP、安全组 ID、账号、口令、密钥、余额与账单明细均已移除。

## 1. 运行层四机

| 节点 | 规格 | 角色 | 网络暴露 |
|---|---|---|---|
| `pt-control` | 4C8G | k6 发压、SSH 跳板、出网代理、证据上传、统一网关与认证服务 | 仅管理网段可访问管理端口；对外只暴露带鉴权的网关入口 |
| `sut-agent` | 4C8G | 被测 Agent 三阶段服务与前端 | 无公网入口，只经控制机网关访问 |
| `dep-services` | 2C4G | MySQL 双库、订单物流服务、数据库与容器指标导出 | 无公网入口，只接受组内互访 |
| `obs-stack` | 4C16G | Trace、Prometheus、Grafana、容器指标 | 观测页面经鉴权或管理网段访问 |

容量测试时，施压端与被测端必须分离；同机压测只能用于冒烟，结果须标注“同机执行”。

## 2. 基础层

| 资源 | 公开说明 |
|---|---|
| VPC 与子网 | 四机部署在同一隔离网段，东西向流量按角色最小开放 |
| 安全组 | 按节点分别授权；公网入方向只保留管理网段与网关端口 |
| 固定公网地址 | 仅控制机保留，跨窗口复用；观测机地址按窗口重建 |
| 加密状态盘 | 保存证书、网关账号摘要与审计日志，跨窗口保留 |
| 对象存储 | 私有桶，保存压测运行证据与回执，开启防误删 |
| 镜像仓库 | 保存钉版镜像，恢复窗口按目标版本拉取 |
| 访问角色 | 证据上传使用最小写权限角色 |

## 3. 访问与鉴权

1. 所有公网可达页面必须自带鉴权；无鉴权页面只允许内网转发。
2. 管理入口只对登记过的管理网段开放；新增出口必须先加白再验证。
3. SSH 只经控制机跳转，内网机不直接暴露公网。
4. 密钥只经环境变量或本机运行时文件注入，不写入正文、脚本或仓库。
5. 账号变更后同步撤销旧会话；窗口重建后重新核对指纹与账号摘要。

## 4. 成本与开窗口径

- 运行层按小时计费，基础层常驻产生少量存储与地址费用。
- 开窗前登记云资源预算、模型预算与当前余额，达到预警线不得开窗。
- 窗口结束优先备份证据；释放运行层必须经人工确认，不得由计划任务自动执行。
- 释放运行层时保留基础层、固定地址、加密状态盘、对象存储与镜像仓库，供下一窗恢复。

## 5. 生命周期

1. 建窗：创建四机、挂载状态盘、绑定地址、拉取钉版镜像、初始化依赖服务与观测组件。
2. 核窗：核对四机健康、服务指纹、数据装载、观测链路与网关鉴权。
3. 开窗：完成预压放行门后再进入正式场景。
4. 收窗：归档逐笔产物、聚合读数、运行清单与回执；恢复被调整过的环境。
5. 关窗：按人工指令释放运行层，核验实例、磁盘与地址无遗留；基础层保留。

## 6. 隔离红线

- 压测流量不得触达生产系统。
- 正式计量期间禁止并行部署、禁止经控制入口做维护操作。
- 数据集、依赖或服务版本变更后，必须重新建立指纹并重跑基线。
- 重建窗口后，服务指纹必须与目标轮次逐字符一致才允许开跑。
- 观测组件与业务负载分离部署，避免观测自耗污染读数。
