# 第 05 讲配套资料

本讲主题：如何建立可信的 Agent 性能基线？

## 模板

| 可复用资产 | 用途 |
|---|---|
| [可复现实验记录](templates/reproducible-experiment-record.md) | 冻结条件、登记配对计划、保留失败与超时，按证据记录比较结论 |
| [版本指纹](templates/version-fingerprint.md) | 对照模型、提示词、代码、依赖、数据、负载、缓存与判断依据的版本差异 |

先登记指纹与声明变量，再填写实验计划。运行后按业务标识与运行标识配对回填，不能把未执行的计划写成优化结果。

## 补充填写表

- [基线与回归判断记录](templates/baseline-regression-record.md)：按基线、差异结论和分位数登记测试结果；实验计划与逐笔配对仍使用上方核心模板。

## 证据附例

版本指纹模板附有[模拟模型轮与真实模型轮的归档指纹对照图](images/image%201.png)。该图只核对 2 份归档清单字段与 12 个装载器文件哈希；模型和门禁口径存在差异，不能用两轮读数直接证明优化收益。

## 来源与范围

模板对应课程第 05 讲的配对实验计划表、基线指纹表、基线批次表和结论写法表。填写时如实登记“尚未执行”“待补”“证据不足”等状态；字符粒度历史批次与确定性词元边界批次分别登记。

本目录提供 2 份核心模板、1 份补充填写表与 1 张证据图，不包含课程正文、项目源码、归档清单原件或逐笔原始数据。正文与完整讲解请在专栏阅读。
