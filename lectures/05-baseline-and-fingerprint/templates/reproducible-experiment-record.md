# 配对实验计划表

实验条件可比之后再比较数字。先填写计划，执行后回填结果，未知项写“待补”，尚未执行写“待测”。版本条件使用[基线指纹表](version-fingerprint.md)逐项核对。

## 实验计划填写区

| 字段 | 填写内容 |
|---|---|
| 实验名称、目的与拟验证假设 | |
| 对照组、候选组及唯一声明变量 | |
| 数据集、订单／物流快照、业务构成及版本／哈希 | |
| 模型、提示词、代码、工具与环境指纹位置 | |
| 负载模型、到达率／并发、时长与预热策略 | |
| 模型加载、提示词缓存、实例／连接池的冷暖状态 | |
| 质量、时延、安全、成本判据及其版本 | |
| 目标指标、绝对服务级别目标与回归容忍值 | |
| 独立任务数、计划总运行数与重复轮次 | |
| 交替／随机执行顺序、配对方法及关联性处理 | |
| 预试验、正式预算、停止规则与最大运行时长 | |
| 差异估计对象、区间算法、置信水平及前提 | |
| 计划状态、负责人和报告版本 | |

模型不暴露的参数写“不支持”或“不可见”，不能补假值。固定随机种子不能代替工具、调度、网络和共享资源条件登记。

## 逐笔配对填写区

同一业务使用相同业务标识，每次执行有独立运行标识。失败、超时、取消及未验证记录必须保留，不能通过删除一对中的失败方改善结果。

| 业务标识 | 重复轮次／执行顺序 | 对照运行标识与终态 | 对照达标状态及判据版本 | 候选运行标识与终态 | 候选达标状态及判据版本 | 轨迹、最终答复与安全证据 | 时延与费用证据 | 缺失、未配对及处理方式 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

对照与候选各自按事前判据记录通过、失败或未验证，正常结束不等于验收达标。

无法逐笔配对时另设分组对照，说明分组依据与比较局限；独立任务数不等于同一任务重复后的总运行数，共享会话、缓存或依赖时段也可能造成样本相关。

## 结果填写区

| 指标与单位 | 对照观察值／样本量 | 候选观察值／样本量 | 差值或比值及方向 | 差异区间／算法／置信水平 | 绝对目标／回归阈值 | 证据状态与结论 |
|---|---|---|---|---|---|---|
| | | | | | | |

时延分位数必须带样本量与算法。完成率保留累计完成数和运行总数，不能用各轮比例的平均代替整体比例；成功业务成本与有效吞吐使用第 04 讲的[成本算式表](../../04-metrics-selection/templates/goodput-ledger.md)。

## 结论写法表

| 证据状态 | 允许的结论 | 后续动作 |
|---|---|---|
| 差异区间整体在越线一侧 | 在所用方法与置信水平下，有证据表明变化超过容忍范围 | 排查并按发布规则处理 |
| 区间跨过门槛或包含门槛值 | 证据不足，尚不能确认是否越线 | 按计划补测；预算耗尽仍保留未决结论 |
| 区间整体在未越线一侧 | 当前证据支持未超过回归门槛 | 继续核验绝对目标及质量、安全、成本；不能据此证明只是随机波动 |
| 无可靠区间或条件不可比 | 只报观察差值与限制 | 补统计依据或重建可比实验 |

直接估计目标差异的区间，不能用两组各自区间是否重叠判断改善。均值方法不能直接套给第 95 百分位；基线为 0 时另定绝对变化规则。观察值越线立即暂停等工程动作与统计结论分别记录。

## 填写示例：配对实验计划，尚未执行

| 字段 | 示例填写 |
|---|---|
| 目的与变量 | 检查压缩物流工具返回内容是否降低成功业务成本，只改变压缩策略 |
| 固定条件 | 同批 205 条工单、相同订单与物流快照；确定性模拟模型，采样温度 0、随机种子 42；提示词、负载、缓存和判断依据不变 |
| 配对标识 | 业务标识 `demo-ticket-001`；对照运行 `demo-control-001-r1`、候选运行 `demo-candidate-001-r1` |
| 开测前待补 | 任务数、轮次、预算、停止规则与完整版本指纹；逐笔关联轨迹、最终答复、费用与安全记录 |
| 当前结果 | 尚未执行，完成率、时延、有效吞吐、成本和差异区间均待测 |

这些标识与计划仅为演示设计，尚未执行，不代表压缩策略已经取得优化收益。
