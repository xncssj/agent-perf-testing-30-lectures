# 版本指纹

对照组和候选组逐项登记实际条件。预先声明的实验变量可以不同，其他差异先评估影响，再决定是否可比或需要重跑；浮动模型别名同时记录调用时间、可见版本与提供方元信息。

## 指纹填写区

| 维度 | 必记内容 | 对照组取值与证据 | 候选组取值与证据 | 是否为声明变量／差异处理 |
|---|---|---|---|---|
| 实验与运行 | 实验版本、批次、业务标识、运行标识、调用时间 | | | |
| 模型与推理参数 | 提供方、模型名、快照；采样温度、候选概率范围、随机种子、最大输出及其他支持参数 | | | |
| 提示词 | 模板标识、版本、完整内容哈希 | | | |
| 编排与代码 | 提交标识、编排版本、迭代／工具调用上限、超时与重试策略 | | | |
| 工具与依赖 | 工具清单、接口版本、协议服务版本、依赖状态 | | | |
| 数据 | 工单、订单、物流、知识与索引版本；冻结清单及文件哈希 | | | |
| 环境与目标 | 目标服务、实例、资源、配置、运行时与实际生效限制 | | | |
| 负载 | 模型、到达率／并发、批次数、时长、预热与执行顺序 | | | |
| 冷暖与缓存 | 模型加载状态、提示词缓存策略与命中、实例／连接池预热 | | | |
| 判断依据 | 质量、时延、安全、成本判据及版本、服务级别目标、门禁和计价 | | | |
| 采集与计量 | 流式／非流式入口、字符／词元边界、计时与分位数算法、观测开关 | | | |
| 证据与结论 | 清单、哈希、逐笔结果位置；未支持、不可见、待补与可比性结论 | | | |

参数不支持或不可见时如实登记，不能补假值。提示词哈希、代码提交和安全判断依据在开测前补齐；执行后回填真实词元用量及逐笔结果。缓存未命中不等于模型重启，3 类冷暖条件须分别记。

## 历史参考：主项目指纹，含待补项

| 维度 | 参考记录 | 证据边界 |
|---|---|---|
| 模型 | 模拟提供方；采样温度 0，最大输出 2000；决策延迟 600±120 毫秒，片段输出约 40 毫秒；随机种子 42 | 延迟为模拟参数，片段曾按字符、后按确定性词元边界切分，必须记录本轮粒度 |
| 提示词 | `system`、`tool_selection`、`response_gen` 共 3 个模板 | 完整内容哈希未保存，属待补，不能当完整复现指纹 |
| 编排与代码 | 当时快照为 1.0.0；最大迭代 10，工具调用上限 5，请求超时 30 秒 | 课程第 05 讲记录代码已升至 2.0.0；历史代码提交未记录，属待补，不推断当前运行值 |
| 工具 | `query_order`、`query_logistics`、`search_knowledge`，本地实现；工具超时 5 秒、重试 2 | 未接外部服务，不能代表真实依赖条件 |

这张参考表是历史条件摘要，不能用其中待补字段填造自己的哈希或提交标识。数据、负载、缓存、环境和判断依据仍须在填写区逐项补齐。

## 证据附例：模拟模型轮与真实模型轮

![2 轮归档清单与装载器哈希对照证据](../images/image%201.png)

| 检查项 | 实验对照结果 |
|---|---|
| 对象 | `20261012-v11-formal3-smoke2` 与 `20261014-v12-real1-b0` 的归档清单 |
| 代码记录 | 基线提交相同；12 个装载器文件中 10 个哈希相同，`config.js` 与 `api.js` 不同 |
| 门禁与运行参数 | 时延目标由 10000 改为 20000 毫秒；迭代参数由 8 改为 33，并启用按业务完成放宽结果判定的参数 |
| 数据 | 数据档清单、工单哈希、数据集版本、规则版本与检索索引版本相同 |
| 目标与模型 | 网关与阶段字段、生效限制相同；目标指纹与模型不同，模拟提供方切为真实模型 |
| 观测条件 | 两轮均开启观测，是共同条件，不是差异项 |
| 可比性结论 | 数据及目标部分条件相同，但模型与门禁口径不可比；需先对齐条件再设计对照，不能证明优化收益或模型优劣 |
| 证据范围 | 只核对 2 份归档清单字段与 12 个装载器哈希，不代表已核验全部源码；本目录未附清单原件或原始运行数据 |
