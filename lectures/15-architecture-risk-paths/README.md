# 第 15 讲配套资料

本讲主题：第二步：怎样分析 Agent 执行架构并找到高风险路径？

本目录提供 3 份模板，对应正文中的三层核对、三类路径分离、三级风险标记、九类候选节点检查与 H1—H7／AW-O1—O3 映射。本目录不包含正文图片、项目源码或逐笔原始数据。

## 模板

| 模板 | 用途 |
|---|---|
| [三层核对与风险标记](templates/architecture-risk-map.md) | 业务／执行／部署三层核对，被测／观测／压测三路分开，高／中／低先验标记 |
| [候选节点九项检查与优先级](templates/candidate-node-checklist.md) | 走一笔业务的五问、九类候选节点核对与三级优先级 |
| [假设—节点风险映射](templates/hypothesis-node-mapping.md) | H1—H7 与 AW-O1—O3 逐项落到候选节点，写明依据与下一步验证 |

## 使用方式与证据状态

1. 架构图是查了之后画的；每条边背后要有核对来源。
2. 先验标记不是结论；门禁全绿也要把观察项映射到图上。
3. 被测、观测、压测三条路径分开记；观测自耗不记成被测容量不足。
4. 候选节点是嫌疑清单，不是判决书；用优先级控制红点数量。
5. 对照集合单独登记来源，不并进主集合；已修复风险不写成当轮瓶颈。
