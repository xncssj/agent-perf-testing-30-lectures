# 第 16 讲配套资料

本讲主题：第三步：一笔业务耗时几十秒，怎样拆分端到端业务时延与服务端耗时？

本目录提供 3 份模板，对应正文中的双口径时间恒等式、单笔时间轴表、关键路径规则、无法归因清单与成本分母核对。本目录不包含正文图片、项目源码或逐笔原始数据。

## 模板

| 模板 | 用途 |
|---|---|
| [双口径时间恒等式](templates/time-split-identity.md) | 客户端墙钟＝服务端耗时＋差值段，两条禁止合并的纪律与闭合核对 |
| [单笔时间轴与关键路径](templates/timeline-record.md) | 时刻表怎么读、空段怎么标、串并行关键路径与单次慢／调用多的区分 |
| [无法归因清单与成本分母](templates/unattributed-and-cost.md) | A1—A4 缺口的补证去向，成本三看与真实轮计价示例 |

## 使用方式与证据状态

1. 两列并排摆，不合并取分位；不用两个 P90 相减代替逐笔差值。
2. 报告固定写“门禁采用客户端墙钟百分位数；服务端百分位数作诊断”。
3. 时间轴是顺序证据，不是求和证据；空白段登记“待分解”，不编原因。
4. 并行分支只取最慢支路；单次慢与调用太多分开判断。
5. 成本分子分母同源，缺失按缺失处理；“无法归因”必须有主人。
