# 双口径时间恒等式

参考课程第 16 讲“先确立时间等式：两个口径不合并，逐笔对应响应时间的关系”中的时间等式与两条纪律。使用说明见[本讲说明](../README.md#使用方式与证据状态)。

## 恒等式

**客户端墙钟 = 服务端耗时 + 差值段**

差值段里装着：压力机侧计时开始后的等待、同机回环、网关加密与鉴权、前端代理、入口接收。各占多少目前拆不开，标记为“不可分”。

## 两条纪律

1. **两列并排摆，禁止合并后再取百分位数**：差值段 P50 5—6ms、P90 约 7ms，只能说明“这一轮链路增量很小”，不能升级成“网关可以忽略”；要升级得补绕开网关的直连对照。
2. **不以聚合百分位数相减代替逐笔分解**：两个 P90 相减得出的“差值段 P90”是错的，百分位数不做减法。

## 恒等式闭合核对

| 核对项 | 示例值 | 要求 |
|---|---|---|
| 逐笔三列 | 客户端墙钟、服务端首字节、服务端总耗时 | 同一笔可配对 |
| 统计范围 | 七轮主要计量窗 7,795 笔（七轮全量 8,917 笔） | 写明窗口与轮次 |
| 服务端耗时缺失 | 0 笔 | 缺失单列，不静默 |
| 首字缺失 | 33 笔 | 单列，不填 0 |
| 差值段分位 | P50 5—6ms、P90 约 7ms | 只描述链路增量 |
| 恒等式闭合 | 每笔可配对并算出差值 | 配对完整 ≠ 机制归因完整 |

## 报告固定两句话

- **门禁采用客户端墙钟百分位数；服务端百分位数作后续瓶颈诊断使用。**
- 逐笔记录里的分位是离散重算；门禁读数以运行产物（`run.json`、`levels.json`）为准，两个口径都写清来源。

## 判定边界

- 差值段只覆盖压力机到应用入口的几跳，服务端内部等待它观测不到。
- 服务端读数用于诊断，不能反过来挑战门禁口径；客户端波动也不能否定服务端分段。
- 配对完整不等于机制归因完整；差值段内部构成仍可能待补证。
