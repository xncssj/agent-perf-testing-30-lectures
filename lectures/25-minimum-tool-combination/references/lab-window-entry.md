# 云窗入口说明（公开脱敏版）

本文件对应第 25 讲正文引用的云窗入口脚本职责说明。完整含内网地址的运维脚本不在本仓库发布。

## 入口职责

| 命令意图 | 作用 |
|---|---|
| 窗口重建 / 续期 | 准备或延长云上压测窗口 |
| 收集产物 | 收窗后把运行产物拉回约定目录 |
| 销毁 | 仅在授权后释放窗口资源 |

## 与本机入口的分工

- 云窗：组织云上发压与收集，观测含主机 / 容器层。
- 本机隔离运行：见公开案例中的 `testing/k6-suite/orchestrator/run-isolated.sh`。
- 单场景冒烟：见 `testing/k6-suite/run-scenario.sh`。

本机冒烟过了，不等于云窗组合过了；两条通道观测边界不同。
