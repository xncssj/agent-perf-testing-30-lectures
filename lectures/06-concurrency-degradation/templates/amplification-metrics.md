# 调用放大指标表

参考课程第 06 讲的调用放大口径。本表用于简要登记，估算方法、历史样本及证据边界见[调用放大估算表](call-amplification-estimate.md)。

| 指标 | 公式 | 分母 | 本场景读数 | 统计口径与样本 | 备注 |
|---|---|---|---|---|---|
| 模型调用放大 | 模型调用总数 ÷ 完成业务数 | 完成业务数 | | | |
| 工具调用放大 | 工具调用总数 ÷ 完成业务数 | 完成业务数 | | | |
| 重试放大 | 尝试总数 ÷ 逻辑调用数 | 逻辑调用数（只看工具层） | | | |

三个指标分母不同，不共用一个名字。重试放大要结合配置与逐笔完成状态判断，不能把本批未触发当成真实负载下没有重试放大。
