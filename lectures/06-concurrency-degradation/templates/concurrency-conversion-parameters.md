# 并发换算参数填写区

参考课程第 06 讲“并发统计有四个层级”“Agent 自己给自己加压”“这两份资产，后面在哪里用”章节中的并发换算参数字段说明。使用说明见[本讲说明](../README.md#参考章节与使用说明)。

本填写区用于填写估算方法、参数来源与验证结果。课程没有提供可直接采用的换算数值，实测回填前不得将估算值作为实测容量依据。

## 参考参数清单

| 换算环节 | 需要回填的参数或证据 | 不能直接替代的内容 |
|---|---|---|
| 用户到会话、业务 | 活跃会话、思考时间、重复提交、实际业务到达率、业务驻留时长与在途业务数 | 在线人数不等于业务并发；设置虚拟用户数不等于实际在途 |
| 业务到模型调用 | 同窗模型在途、每笔调用数、调用时序、串并行关系及模型调用驻留时长 | 模型调用放大约 2.65 是次数比，不能直接作为同时并发比 |
| 业务到工具或检索调用 | 同窗工具在途、分支并行关系、重试尝试、连接池等待与驻留时长 | 工具放大约 1.65、重试放大 1.0 是单点，不能代表高负载预算 |
| 会话上下文影响 | 轮数分布、窗口占用率、每轮提示词元增量及压缩、剪枝事件 | 历史字符估算口径不能当作已采集的逐轮词元增长 |

只有同一时间窗、同一统计边界与同一取值方式的并发读数才可计算比值。平均、峰值、分位数不能任意互除；累计调用次数与同时在途调用数分开登记。

## 证据与使用边界

- 数值为空表示待采或待回填，不代表系数为 0；没有证据的参数不得进入实测容量报告。
- 模型、工具和重试次数比只能描述该批调用构成。循环、扇出和重试的拆解不能重复加总已统计的调用，重试也不能重复计为新业务。
- 队列未采、开放负载未跑、高并发聚合缺口待修时，须同时登记限制；不能用未校验的换算消除这些缺口。
- 多智能体架构变化后，重新采集调用构成、时序和驻留，不沿用单智能体的 2.65 单点作为新架构容量预算。
