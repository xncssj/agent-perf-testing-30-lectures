# 容量风险填写区

参考课程第 06 讲的退化信号与现场判断步骤。本填写区用于简要登记，候选拐点与安全容量的完整证据要求见[容量风险表](capacity-risk-checklist.md)。

| 判据项 | 定义或阈值来源 | 本场景取值 | 观测证据 | 状态 |
|---|---|---|---|---|
| 队列深度与等待时长 | 排队请求数、运行中请求数是否持续累积 | | | |
| 时延越界 | 首字时延、端到端时延或长尾分位数越过 SLO | | | |
| 质量下滑 | 业务完成率与结果合格率随负载下降 | | | |
| 错误与超时 | 请求失败、超时、熔断跳过的比例上升 | | | |
| Goodput 走平或下弯 | 连续压力档次有效吞吐量不再增长 | | | |
| 单并发效率下降 | 单个并发的 Goodput 回落 | | | |
| 安全容量区间 | 实际负载上升且核心 SLO 仍满足、Goodput 未走平、队列未持续累积的最高负载区间 | | | |

## 现场三步判断

| 步骤 | 动作 | 本场景结论 |
|---|---|---|
| 1 | 先看实际负载有没有上升，没涨先查压测脚本 | |
| 2 | 再看四类信号有没有越线，任一成立停止加压并排查 | |
| 3 | 确认负载上升后，Goodput 走平或下弯再标记候选拐点 | |

未采集的判据项标“待采”，不写成已观测。
