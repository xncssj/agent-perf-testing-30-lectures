# 负载模型选择表

| 负载模型 | 适用入口与目的 | 能回答什么 | 局限 | 本场景是否采用 |
|---|---|---|---|---|
| 封闭模型 | 固定虚拟用户，一笔业务做完才发下一个 | | 系统过载时到达率自动下降，容易低估排队 | |
| 开放模型 | 按到达率发业务，接近真实入口 | 排队与过载行为 | | |
| 阶梯负载 | 逐步抬高并发，每档稳定运行 | 定位拐点与安全容量 | 档位太短不能下稳态结论 | |
| 突发 | 瞬时把流量顶上去再砍下来 | 弹性、限流与降级能否接住 | | |
| 骤降 | 流量快速砍下来 | 积压队列多久排空 | | |

选择规则：业务入口是哪种到达模式，主模型就选哪种，其余用来补盲区。
