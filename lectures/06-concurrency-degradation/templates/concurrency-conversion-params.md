# 并发换算参数填写区

参考课程第 06 讲的并发换算口径。本填写区用于按参数简要登记，分层换算方法、适用前提与证据要求见[并发换算参数填写区（分层换算）](concurrency-conversion-parameters.md)。

| 参数 | 含义 | 取值来源或估算方法 | 当前状态 | 回填证据 |
|---|---|---|---|---|
| 业务到达率 | 单位时间提交的业务数 | | 待估算 | |
| 业务并发 | 同时在执行的业务数 | | 待实测 | |
| 在途业务数 | 落到系统上的实际负载 | | 待实测 | |
| 每线程业务数 | 每个虚拟用户执行的业务数 | | 待确认 | |
| 线程时长 | 每个压力档位持续的时间 | | 待确认 | |
| 业务驻留时间 | 一笔业务从进入系统到终态的时间 | | 待实测 | |
| 模型调用放大 | 模型调用总数 ÷ 完成业务数 | | 待实测 | |
| 工具调用放大 | 工具调用总数 ÷ 完成业务数 | | 待实测 | |
| 重试放大 | 尝试总数 ÷ 逻辑调用数 | | 待实测 | |
| 下游调用并发 | 模型与工具调用的在途峰值 | | 待实测 | |

没有实测回填之前，这些参数不进容量报告。封闭模型里的虚拟用户数不进第 04 讲的业务级统计。
