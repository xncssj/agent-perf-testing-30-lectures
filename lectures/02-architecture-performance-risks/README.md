## 来源与使用边界

2 份模板对应课程第 02 讲的“风险动作表”“风险登记表”，均提供项目填写区。取消传播示例为未验证假设，实际配置、观察窗口和清理时限需要补齐。

历史实验记录验证熔断跳过、降级与故障隔离，不能替代取消传播验证；降级不虚构事实也不等于配送业务完成。本目录提供实验汇总，不包含逐笔原始数据。
