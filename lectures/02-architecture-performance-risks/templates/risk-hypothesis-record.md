# 风险假设记录

来源：课程第 02 讲“风险登记表”。将风险假设、预期判据、验证动作与实际结果分别填写；参考同类历史实验不能代替本条假设的验证。

## 运行与证据关联

| 项目、数据与配置版本 | 业务标识／运行标识 | 步骤、父子任务、请求与轨迹标识映射 | 业务交付与判断依据 | 复核人／时间 |
|---|---|---|---|---|
| | | | | |

## 风险记录填写区

| 字段 | 填写内容 |
|---|---|
| 执行段与风险假设 | |
| 配置依据 | |
| 预期终态与停止判据 | |
| 观察窗口 | |
| 验证动作 | |
| 证据位置 | |
| 实测结果与结论 | |

观察窗口覆盖异常前、传播、清理和已调度重试可能触发的时段。停止派发、内层结束及剩余活动要分别取证，不能只凭暂时没有新日志判断已停止。

## 填写示例：取消传播假设，尚未验证

| 字段 | 示例填写 |
|---|---|
| 执行段与风险假设 | 异常工单转入智能体子流程，外层超时后内层可能继续调用模型并占用资源 |
| 配置依据 | 主项目多智能体配置：外层超时 8000 毫秒、子智能体超时 3000 毫秒、最多重试 3、熔断阈值 5（窗口 30000 毫秒）、并行上限 8、降级开启、退避 50 毫秒；取消传播规则和允许清理时长尚未单列，属待补 |
| 预期终态与停止判据 | 在业务契约要求取消的前提下，外层记录超时，内层在约定传播时限内确认取消、停止新调用，并在清理时限内结束已有活动；业务结果另按配送查询和交付证据判定 |
| 观察窗口 | 从外层超时前到取消传播、清理及潜在重试结束；实际起止时间待配置明确后回填 |
| 验证动作 | 在隔离环境让查询超过外层时限，关联父子任务，采集取消到达、内层结束、新增调用、剩余活动及资源用量 |
| 证据位置 | 同次运行响应中的耗时分解与轨迹、终态、用量；原始记录位置由实际执行者填写 |
| 实测结果与结论 | 未验证，实际终态、时间戳、窗口内调用及用量尚未填写 |

如果业务契约允许后台继续执行，应另填终态与预算要求，不能套用取消判据。示例配置用于设计验证，不代表取消验证已经执行；缺失配置须在执行前补齐。

[案例 2 实验记录](../experiments/case-2-multi-agent.md)验证的是熔断跳过、降级与故障隔离：受影响 12 笔、不受影响 4 笔及已记录兄弟智能体 10 次调用的结果，不能据此判定取消传播通过。

记录保留失败、超时、取消和未验证业务；证据关联缺失时先补齐，不把不同运行的材料拼在一起。结论只覆盖记录的配置、观察窗口和验证场景。
