# 第 08 讲配套资料

本讲主题：老板只说客服工单 Agent 要“快、稳、准、省”，怎样变成可验收的需求？

本目录提供 4 份模板，对应正文中的业务底数表、性能需求表、四步定标表、两套目标表、SLO 卡片表、工单构成表与判定顺序表。本目录不包含正文图片、项目源码或逐笔原始数据。

## 模板

| 模板 | 用途 |
|---|---|
| [性能需求表](templates/performance-requirements.md) | 先摸业务底数，再把“快、稳、准、省”写成含指标、目标、证据状态的需求条款 |
| [SLO 卡片](templates/slo-card.md) | 四步定标、生产与压测两套目标、测量入口、分母与证据状态 |
| [工单构成与判定字段](templates/ticket-composition.md) | 六类工单构成、关联快照、判定字段与数据版本纪律 |
| [验收判定顺序表](templates/acceptance-order.md) | 红线、P0、P1 的固定判定顺序与风险接受边界 |

## 使用方式与证据状态

1. 先填业务底数，再写需求表；找不到业务对照物的格子标“待回填”，不要填拍脑袋数字。
2. 两套目标表分开记，结论只能同环境比较；压测环境达标不等于生产达标。
3. “待回填”“待确认”“待补采集门禁”“候选验收项”都表示尚未完成，不能写成对外承诺。
4. Goodput 是吞吐量口径，不是百分比；业务所需与系统实测是两笔账。
5. 判定顺序从上往下走，一次只下一个结论；红线与 P0 失败不接受风险接受。
