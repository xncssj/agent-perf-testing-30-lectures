# SLO 卡片

参考课程第 08 讲“四步走，把四个字翻译成 SLO”“Goodput 这两行，目标值现在不能写”中的“四步定标表”“两套目标表”“SLO 卡片表”。使用说明见[本讲说明](../README.md#使用方式与证据状态)。

## 四步定标表

| 步骤 | 干什么 | 示例 |
|---|---|---|
| 1. 定性能指标（SLI） | 选可测量的服务级别指标 | TTFT、TPOT、端到端时延（E2E）、Goodput、合格率等 |
| 2. 定业务目标（SLO） | 业务可接受的目标值，三方确认 | 见下方两套目标表 |
| 3. 定异常指标 | 允许坏到什么程度 | 可用性 99.9%，按 30 天换算每月允许不可用约 43 分钟 |
| 4. 定验收方式 | 怎么测、用什么数据集、什么环境 | 245 条版本化工单用例集 + 基准/容量/稳定性场景 |

**SLO 卡片必须经测试、业务、开发三方确认，缺任一方确认不进入正式验收。** 测试方定指标和口径，业务方确认目标值，开发方确认可行性。

## 两套目标表

生产目标与压测环境目标分开记，结论只能同环境比较。

| 指标 | 生产目标 | 压测环境目标 | 证据状态 |
|---|---|---|---|
| TTFT（P90，候选目标） | ≤ 2s | ≤ 1.5s | 正式链路走非流式，待流式专项采集 |
| TPOT（P90，候选目标） | ≤ 100ms | ≤ 80ms | 依赖可靠的 Token 边界证据 |
| E2E 时延（P90） | ≤ 15s（待三方确认） | ≤ 10s | 客户端墙钟为门禁唯一来源 |
| 并发能力（用户并发） | ≥ 100 并发用户下 P0 项仍达标 | 按压力台阶逐级实测 | VU 不等于在线用户，待行为模型对齐 |
| Goodput·业务所需（合格业务/秒） | 待高峰数据回填 | 待高峰数据回填 | 高峰系数缺失 |
| Goodput·系统实测（合格业务/秒） | 待基线实测回填 | 待基线实测回填 | 分脚本口径与业务级两层 |
| 业务完成率 | ≥ 95% | ≥ 98% | 完成不等于合格 |
| 工具选择准确率 | ≥ 90%（待补采集门禁） | ≥ 95% | 当前只有工具覆盖率观测项 |
| 结果合格率 | ≥ 85% | ≥ 90% | 判定器只查“该出现的有没有出现” |
| 可用性 | ≥ 99.9% | ≥ 99.5% | 一次跑批验不出月度可用性 |
| 错误率 | ≤ 1% | ≤ 0.5% | 按请求笔数算 |
| 超时率 | ≤ 2% | ≤ 1% | 与业务失败分开统计 |
| 恢复时间 | ≤ 30s | ≤ 15s | 依赖故障注入能力 |
| 人工转接率 | ≤ 20% | ≤ 15% | 业务口径 |
| 单次成本（候选验收项） | ≤ ¥0.5/单（暂定） | ≤ ¥0.3/单（暂定） | 单价待业务方确认 |
| Token 消耗（窗口平均，候选验收项） | 平均 ≤ 2000/单 | 平均 ≤ 1500/单 | 分母是窗口内全部业务 |
| 成本节省率（业务论证项） | ≥ 60%（暂定） | ≥ 70%（暂定） | 人工基线未回填前不进验收 |

## SLO 卡片表

| 卡片要素 | 约定 |
|---|---|
| 统计对象与窗口 | 按指标分场景记录：基准场景全量一轮、判定取实测窗口（预热样本不计入）；容量按台阶记录样本数、工单 ID 覆盖数与类型构成；可用性由上线后月度监测验收；分位数带样本量与算法 |
| 数据集与场景 | schema 版本、随机种子、用例集版本；基准、容量、稳定性三类场景 |
| 环境分开记 | 生产目标须线上对等环境；压测环境结论不外推为生产结论 |
| 采集点 | E2E 以压测端客户端墙钟为判定与门禁唯一来源；服务端耗时只作诊断，缺失单列不回退混入 |
| 分母 | 合格率、错误率、超时率的分母是窗口内全部业务；成功业务成本的分母是合格业务数 |
| 过程约束 | 模型与工具调用放大、循环轮次、重试率按场景观测，较基线上涨约三成预警 |
| 成本与 Token 证据条件 | 每笔都要有用量；缺失记缺失，不摊派、不填 0；单次成本 = 窗口 Token 总价 ÷ 合格业务数 |
| 证据状态 | 未回填、未确认、未实现的行分别标注，不得混写成已验收 |

## 判定边界

- Goodput 是吞吐量（合格业务数/秒），不是百分比；业务所需与系统实测是两笔账，不能互相替代。
- 均值与分位数不能互相换算；P90 稳不代表 P99 有证据。
- TTFT、TPOT、单次成本、Token 在采集与门禁补齐前只是候选目标，不是正式验收项。
- 本卡片不包含项目源码、逐笔原始数据或归档清单；正文与完整讲解请在专栏阅读。
