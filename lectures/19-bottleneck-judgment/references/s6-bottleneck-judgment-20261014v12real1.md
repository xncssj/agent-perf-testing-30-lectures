## 二、判定结论（2026-10-14 深夜老板拍板确认，原候选 C1/C2 转正）

**结论一（原 C1，主约束定性）**：本轮 run_set 内，系统吞吐与时延的**主约束是外部 LLM 推理时延与调用链串行性（一次决策可返回多个工具、逐一执行）**（外部 API 属性 + SUT 架构属性叠加）——证据强度：三环闭合（现象/轨迹/计数器互相自洽）＋机制环方向支持（span 量级证据、机制等式未闭合）；限定：外部侧为阴性排除法（U3 黑盒），无 DeepSeek 侧正向指标；控制实验环未闭合（结论为判定级，非实验反转级）。

**结论二（原 C2，SUT 侧判定）**：**SUT 侧（含网关/前端/工具池/DB）尚无证实瓶颈**——本侧候选经 S3（差值段稳态量级）+S4（资源零同形）+S5（工具成分 3/5ms）三步对照仍无证实项，**非全排除**：入口直连对照未执行（D3 挂账）、tinyproxy 代理等待在服务端耗时内部未单列（S4 边界注保留待验证）、首字剩余段约 3.0s 未拆（S5 §二）；SUT 在 50VU 内资源占用 ≤8%、Goodput 逐档单调上升。与 formal 系 Mock 轮「SUT 侧无瓶颈」负结论同型，但机制不同（Mock 轮约束=固定延迟谱设计，本轮约束=真实推理时延）。

**未排除因素（随结论携带）**：①O-GAP1 致歉/生成段约 12.6s 无 observation 覆盖（final_answer 有记录但零时长；观测缺口，非性能结论障碍）；②U2 tinyproxy 无专用序列（以整机 CPU 代理判读，L50 时两机均 <0.36 核——整机占用低不证明等待影响可忽略，代理等待在服务端耗时内部、差值段测不到，保留待验证）；③高档位 P90 +13—20% 的外部排队成分无正向证据（阴性排除法限定）；④控制实验环缺（C1 的因果方向未经实验反转验证）。
