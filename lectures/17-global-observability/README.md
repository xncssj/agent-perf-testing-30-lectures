## 使用方式与证据状态

1. 四层同期对照只回答“哪一层跟着时延动”，不回答“哪个调用”。
2. 三种出口之外没有第四种；“有点可疑先记着”不能写进结论。
3. 时序数据带时间窗、层级、查询条件；证据缺一项只是主观感受。
4. 高占用不等于瓶颈，低 CPU 不等于无等待，内存形态不等于泄漏。
5. 推理侧与上下文没有直接指标就登记缺口，不拿行业常识冒充本轮证据。
