# 推理侧与上下文证据状态

参考课程第 17 讲“推理侧与上下文：有则记，无则登记”中的观测状态。使用说明见[本讲说明](../README.md#使用方式与证据状态)。

## 三种证据状态

| 状态 | 含义 | 写法 |
|---|---|---|
| 有直接指标 | 有可查询的序列或事件 | 写指标名、时间窗、查询条件 |
| 只有间接痕迹 | 计价、Token 等侧面线索 | 标“间接”，不升级为机制已查实 |
| 尚未采集 | 本轮没有数据 | 标“未采／待补”，不拿行业常识冒充证据 |

## 观测状态表

| 观测项 | 本轮状态 |
|---|---|
| 排队与运行中的请求数、并发槽位占用 | 外部服务商侧黑盒，只有本侧阴性证据 |
| KV Cache 与前缀缓存命中 | 无直接序列；只有计价侧痕迹——缓存命中把有效单价压到约 ¥1.21/M |
| 批处理对长尾 | 未采 |
| 上下文窗口占用与上下文事件（注入、压缩、剪枝） | 无直接通道；只有 Token 分桶侧面核对——长稳 5,523 笔均值 3,617 Token/笔，逐桶 3,440—3,718，收尾小桶（17 笔）5,243；构成与缓存贡献未分解，膨胀仍是候选 |

## 使用纪律

1. 外部模型的计价与 Token 只作辅助，不能代替缓存、排队和上下文机制的直接观测。
2. 候选机制可以提，证据状态必须写“未采／待补”。
3. TPOT 只能来自真实流式样本；非流式窗口不得估算，更不许手绘 TPOT 曲线。
4. 轨迹条数不是业务笔数；业务总数以逐笔判定记录为准。

## 判定边界

- 低资源占用与计价痕迹都不能单独证明“外部模型慢”。
- 观测条数与业务笔数分账：主计量窗每笔都有判定记录，账才闭合。
- 单笔内观察项只能看量级，不能当精确数；缺段就标缺段，不推断全部。
